# EventApp

EventApp is a powerful and user-friendly platform designed to help you discover, manage, and organize events with ease. Whether you're planning a conference, searching for local meetups, or promoting your own events, EventApp provides all the tools you need.

## Features

- **Event Discovery:** Search and filter events by category, location, and date.
- **Create & Manage Events:** Easily create, edit, and delete your events.
- **User Authentication:** Secure login and registration for event organizers and attendees.
- **Interactive Map:** View events on a dynamic map for better location awareness.
- **RSVP & Attendance Tracking:** Allow users to RSVP and track attendance automatically.
- **Notifications:** Get updates about new events, changes, and reminders.
- **Mobile Friendly:** Responsive design for use on any device.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14+)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- Database (e.g., MongoDB, PostgreSQL, or as specified in your app)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/FlorentBajraktari/EventApp.git
   cd EventApp
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Set up environment variables:

   - Copy `.env.example` to `.env` and fill in your configuration.

4. Run the development server:

   ```bash
   npm start
   # or
   yarn start
   ```

## Usage

- Access the app at `http://localhost:3000`
- Register or login to explore events
- Create your own events and invite others
